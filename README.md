# Поездки на человека в год · Краснодарский край · 2025

Интерактивная тёмная карта населённых пунктов Краснодарского края по показателю
«число поездок в год на человека» (2025).

**Как читать карту:**
- длина светящегося красного кольца — число поездок на человека в год (4,5–773,7);
- площадь круга — численность населения;
- серый пунктирный круг — данных нет (пропуски не заменены нулями);
- при наведении — название, население и число поездок.

**Источник данных:** Росстат, 2025. Базовая карта © Esri. Карта построена
библиотекой [LLMaps](https://github.com/greadr71/LLMaps) (MapLibre GL JS).

## Файлы
- `index.html` — карта (GitHub Pages)
- `krasnodar_transport_2025_source.csv` — исходные данные без изменений
- `krasnodar_transport_2025_processed.json` — обработанные данные

## Локальный запуск
Открыть `index.html` в браузере или `python3 -m http.server` в папке репозитория.
